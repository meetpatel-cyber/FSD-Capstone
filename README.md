# FSD Capstone Project

A Full Stack Development capstone project built using React, Vite, Bootstrap, Node.js, Express, and MongoDB.

## Live Website

**[Visit FSD Capstone Website](https://fsd-capstone-19ll.onrender.com/)**

## Technologies Used

- React.js
- Vite
- Bootstrap 5
- React Router DOM
- Node.js
- Express.js
- MongoDB
- Mongoose

## Project Structure

- `client/` – Frontend application
- `server/` – Backend application
